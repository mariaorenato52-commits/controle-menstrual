        Dados e privacidade

        Onde ficam os registros

        • As anotações ficam salvas somente neste navegador, neste dispositivo (armazenamento local do navegador, localStorage).
        • O login usa Supabase Auth. O e-mail e a senha são enviados ao Supabase para autenticação; as anotações do diário não são enviadas a ele, a terceiros ou para armazenamento em nuvem.
        • O login libera a interface, mas não criptografa os registros locais. Como o app é estático, alguém com acesso ao dispositivo ou que altere o código no navegador pode contornar essa tela.
        • Os dados não são criptografados. Qualquer pessoa com acesso a este navegador/usuário do computador ou do celular pode abrir o app e ler as anotações. Use o bloqueio de tela do dispositivo.
        • Os dados podem ser perdidos se você limpar os dados de navegação/do site, usar janela anônima, desinstalar o navegador, trocar de dispositivo, ou se o navegador liberar espaço automaticamente. Exporte um backup de vez em quando.
        • Outro navegador ou outro endereço (por exemplo, outra porta) enxerga um diário separado e vazio.

        Acesso

        Sessão ativa.

        Exportar

        Baixa um arquivo .json com todas as anotações. O arquivo não é criptografado: guarde-o em local seguro.

        Importar backup

        Restaura um arquivo exportado por este app. As anotações atuais são mantidas; anotações com o mesmo identificador são substituídas pela versão do arquivo.

        Apagar todos os registros

        Remove permanentemente todas as anotações deste dispositivo. Não é possível desfazer. Exporte antes se quiser guardar uma cópia.
